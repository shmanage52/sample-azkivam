# صفحه‌ی راهنمای خرید شمش اکسیراز با ازکی وام

نمونه‌ی اولیه‌ی یک صفحه‌ی راست‌چین و واکنش‌گرا برای معرفی مسیرهای خرید آنلاین و حضوری شمش.

## انتشار با GitHub Pages

1. فایل‌های `index.html` و `README.md` را در ریشه‌ی یک مخزن GitHub قرار دهید.
2. در مخزن، وارد **Settings → Pages** شوید.
3. در بخش **Build and deployment**، گزینه‌ی **Deploy from a branch** را انتخاب کنید.
4. شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و ذخیره کنید.
5. پس از پایان انتشار، نشانی سایت در همان بخش Pages نمایش داده می‌شود.

صفحه برای نمایش دسکتاپ و موبایل تنظیم شده است. لوگوهای اکسیراز و ازکی وام و فونت Vazirmatn از نشانی‌های آنلاین بارگیری می‌شوند؛ بنابراین برای نمایش کامل، اتصال اینترنت لازم است.
